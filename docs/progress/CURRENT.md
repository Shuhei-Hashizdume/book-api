- 現在どのPhase・Stepにいるか

過去の重要な完了事項・設計判断・問題と解決などは、
`docs/progress/HISTORY.md` に記録します。

# Codexへの更新ルール

このファイルは、開発・学習の進行に合わせてCodexが更新してください。

特に以下の場合は更新を検討してください。

- Stepを完了した
- 次のStepへ進んだ
- Phaseが変わった
- 作業を中断する
- 次回の再開地点が変わった
- 未解決の問題が発生した
- 未解決の問題が解決した

更新するときは、

**古い現在地を残し続けるのではなく、最新の状態がすぐ分かるように整理してください。**

長期的に残す必要がある情報は、
`docs/progress/HISTORY.md` へ移してください。
