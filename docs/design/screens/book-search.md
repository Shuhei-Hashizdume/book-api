# 書籍検索画面 設計書

**ファイル名:** `docs/design/screens/book-search.md`  
**対象画面:** 書籍検索画面  
**設計状態:** 主要仕様確定  
**関連画面:** 本棚画面、検索結果の書籍詳細画面

---

## 1. 画面の目的

ユーザーが本のタイトルまたは著者名から書籍を検索し、気になる本を見つけられるようにする。

検索結果から書籍の詳細画面に進み、読書状態や優先度などを設定して自分の本棚に追加できる。

本画面は**書籍を探すための画面**であり、本棚への登録操作は検索結果の書籍詳細画面で行う。

## 3. 表示項目

| 項目         | 表示内容             | 備考                         |
| ------------ | -------------------- | ---------------------------- |
| 戻るリンク   | ← 本棚に戻る         | 本棚画面へ遷移               |
| 画面タイトル | 🔍 本を探す          | 固定表示                     |
| 検索入力欄   | タイトル・著者を入力 | 文字列入力                   |
| 検索ボタン   | 検索                 | 検索処理を実行               |
| 検索結果一覧 | 書籍を縦方向に表示   | 最大40件                     |
| 書籍の表紙   | 表紙画像             | 画像がない場合は代替アイコン |
| 書籍タイトル | 本のタイトル         | 検索結果データを使用         |
| 著者名       | 著者                 | 検索結果データを使用         |
| 遷移表示     | ＞                   | 書籍詳細へ進めることを示す   |

検索結果一覧には「登録済み」のバッジを表示しない。

書籍がすでに本棚に登録されているかどうかは、検索結果の書籍詳細画面で扱う。

## 4. 検索仕様

### 4.1 検索対象

- 書籍タイトル
- 著者名

ユーザーは1つの入力欄から検索する。

### 4.2 検索開始条件

以下の操作で検索する。

1. 「検索」ボタンを押す
2. 入力欄でEnterキーを押す

入力途中の自動検索（ライブ検索）は行わない。

### 4.3 未入力時の動作

検索欄が空の状態で検索を実行した場合は、APIを呼び出さず、検索キーワードの入力を促す。

### 4.4 検索結果件数

- 最大40件を表示する。
- 検索結果は縦一覧で表示する。
- MVPではページネーションを設けない。
- 検索結果は画面内で縦スクロールできる。

## 5. 画面の状態

### 5.1 初期状態（検索前）

検索結果一覧は表示せず、検索を促す案内文を表示する。

```text
🔍 本を探す

[ タイトル・著者を入力 ] [検索]

読みたい本を検索してみましょう
```

### 5.2 検索中

検索処理中はローディング表示を行う。

```text
検索しています...
      ◌
```

### 5.3 検索成功

検索結果が1件以上ある場合は、書籍一覧を表示する。

各行をタップまたはクリックすると、該当書籍の検索結果詳細画面へ遷移する。

### 5.4 検索結果0件

該当する書籍が見つからなかった場合は、以下のように表示する。

```text
該当する本が見つかりませんでした

タイトルや著者名を変えて
もう一度検索してみてください
```

検索欄のキーワードは保持する。

### 5.5 通信エラー

検索APIの呼び出しに失敗した場合は、エラーメッセージと再試行ボタンを表示する。

```text
本を検索できませんでした

通信状況を確認して
もう一度お試しください

[ 再試行 ]
```

再試行ボタンは、保持している検索キーワードで検索を再実行する。

## 6. 操作と画面遷移

### 6.1 本棚から検索画面へ

```text
本棚画面
   │
   │「＋ 本を探す」
   ▼
書籍検索画面
```

### 6.2 検索結果から書籍詳細へ

```text
書籍検索画面
   │
   │ キーワードを入力して検索
   ▼
検索結果一覧
   │
   │ 書籍を選択
   ▼
検索結果の書籍詳細画面
```

検索結果詳細画面の登録フォームや本棚への追加処理は、別ファイル `book-search-detail.md` で定義する。

### 6.3 検索結果詳細から戻る

```text
書籍検索画面
   │
   │「Python」で検索
   ▼
検索結果一覧
   │
   │ 書籍Aを選択
   ▼
検索結果の書籍詳細
   │
   │「← 検索結果に戻る」
   ▼
書籍検索画面
   │
   ├─ 検索キーワード：「Python」を保持
   ├─ 検索結果：保持
   └─ スクロール位置：先頭
```

検索結果詳細から戻っただけで検索条件を消去したり、不要な再検索を行ったりしない。

### 6.4 本棚へ戻る

画面上部の「← 本棚に戻る」を押すと、本棚画面へ遷移する。

本棚画面へ通常のナビゲーションで戻った場合は、`bookshelf.md` に定義されたタブ選択・スクロール位置のルールに従う。

## 7. APIとの関係

### 7.1 書籍検索API

```http
GET /books/search?q={検索キーワード}
```

用途：入力されたキーワードを使用して書籍を検索する。

フロントエンドはBookAPPのバックエンドAPIを呼び出す。

バックエンド内部では外部の書籍検索サービスを利用するが、**ユーザー向け画面に外部サービス名を表示しない**。

### 7.2 検索結果データ

画面で利用する主なデータは以下。

- 書籍の外部識別子
- タイトル
- 著者
- 表紙画像URL
- ジャンル（詳細画面への引き継ぎ用）

外部識別子・タイトル・著者が必須条件を満たさない書籍は、バックエンド側の検索結果処理で除外する想定。

表紙画像が存在しない場合は、フロントエンドで代替アイコンを表示する。

ジャンルが存在しない場合の表示は、検索結果詳細画面側で扱う。

## 8. レスポンシブ対応

### PC版

- 共通ヘッダーを表示する。
- 左側にサイドバーを表示する。
- メイン領域に検索フォームと検索結果を表示する。
- 検索入力欄と検索ボタンを横並びにする。

### スマホ版

- 共通ヘッダーを表示する。
- 下部にナビゲーションを表示する。
- 検索入力欄と検索ボタンを縦方向に配置する。
- 書籍一覧は画面幅に合わせて縦表示する。
- 横スクロールを前提としない。

## 9. この画面で行わないこと

本画面の責務を明確にするため、以下は対象外とする。

- 書籍の本棚登録
- 読書状態の設定
- 読む優先度の設定
- おすすめ度の設定
- 登録済み書籍の編集・削除
- 気づきの登録
- AI提案の表示
- ライブ検索
- 検索結果のページネーション

これらは必要に応じて、それぞれ対応する画面の設計書で扱う。

## 10. 確定事項と実装時の確認事項

### 確定事項

- 1画面につき1つのMarkdownで管理する。
- 画面上部に「← 本棚に戻る」を表示する。
- タイトル・著者で検索する。
- 検索ボタンまたはEnterで検索する。
- 最大40件を縦一覧表示する。
- 検索結果から検索結果書籍詳細画面へ遷移する。
- 検索結果一覧には登録済みバッジを表示しない。
- 詳細画面から戻った場合、キーワードと結果を保持する。
- 詳細画面から戻った場合、スクロール位置は先頭にする。
- 未検索、0件、検索中、通信エラーの表示を用意する。
- 外部の書籍検索サービス名をユーザー向け画面に表示しない。

### 実装時の確認事項

- 既存の検索APIのレスポンス形式とフロントエンドで必要なデータの対応。
- 検索結果の保持方法（画面状態管理など）。
- 既存APIが最大40件を返すかどうか。
- 検索結果詳細画面へのデータの受け渡し方法。
- スマホ版の共通ナビゲーションの正確な項目・表示形式。

これらは未確定の技術的事項であり、画面の主要なUX仕様を再検討するためのものではない。
