# 検索結果の書籍詳細画面 設計書

**ファイル名：** `docs/design/screens/book-search-detail.md`  
**対象画面：** 検索結果から開く、書籍登録前の詳細画面  
**設計状態：** 主要UX仕様確定

---

## 1. 画面の目的

書籍検索で見つけた本の情報を確認し、読書状態・読む優先度またはおすすめ度を設定して、自分の本棚に追加する。

本画面は**本棚に登録する前の書籍詳細画面**であり、登録済み書籍を編集・削除する `book-detail.md` とは区別する。

## 2. PC版ワイヤーフレーム

```text
┌────────────────────────────────────────────────────────┐
│ BookAPP                                  ユーザー ▼    │
├──────────────┬─────────────────────────────────────────┤
│ ホーム       │ ← 検索結果に戻る                        │
│ 本棚         │                                         │
│ 気づき       │ ┌──────────┐  本のタイトル              │
│ タイムライン │ │          │  著者：著者名              │
│ マイページ   │ │   表紙   │  ジャンル：技術書          │
│              │ │          │                            │
│              │ └──────────┘                            │
│              │                                         │
│              │ 読書状態                                │
│              │ (●) 未読  ( ) 読んでる  ( ) 読んだ      │
│              │                                         │
│              │ 読む優先度                              │
│              │ (●) 読みたい                            │
│              │ ( ) そのうち読みたい                    │
│              │                                         │
│              │            [ 本棚に追加 ]              │
└──────────────┴─────────────────────────────────────────┘
```

### 「読んだ」を選択した場合

```text
読書状態
( ) 未読  ( ) 読んでる  (●) 読んだ

おすすめ度（必須）
☆ ☆ ☆ ☆ ☆

          [ 本棚に追加 ]
```

この場合、読む優先度の選択欄は表示しない。

## 4. 書籍情報の表示

| 項目       | 表示仕様                               |
| ---------- | -------------------------------------- |
| 表紙       | 検索結果の画像。なければ代替アイコン   |
| タイトル   | 必須                                   |
| 著者       | 必須                                   |
| ジャンル   | 検索結果のジャンル。なければ「その他」 |
| 戻るリンク | 「← 検索結果に戻る」                   |

書籍の概要・あらすじ、ISBN、登録日は表示しない。

検索結果から受け取った書籍情報を使用する。MVPでは、この画面を開くためだけの外部書籍詳細APIは追加しない。

## 5. 読書状態の設定

選択肢は以下の3つ。

- 未読
- 読んでる
- 読んだ

初期値は**未読**。

読書状態に応じて、入力項目を切り替える。

| 読書状態 | 表示する入力 |
| -------- | ------------ |
| 未読     | 読む優先度   |
| 読んでる | 読む優先度   |
| 読んだ   | おすすめ度   |

## 6. 読む優先度

選択肢は以下の2つ。

- 読みたい
- そのうち読みたい

初期値は**読みたい**。

「未読」「読んでる」を選択したときに表示する。

「読んだ」を選択した場合は非表示にするが、画面内で再び「未読」「読んでる」に切り替えた場合は、直前に選んでいた優先度を復元する。

## 7. おすすめ度

「読んだ」を選択したときだけ表示する。

- ★1〜5から選択
- 未選択では登録できない
- 選択した星の数を視覚的に確認できる
- 「未読」「読んでる」に切り替えた場合は非表示

画面内で読書状態を切り替えても、すでに選択したおすすめ度は保持し、再び「読んだ」に戻した場合は復元する。

## 8. 登録済み書籍の場合

対象の書籍がすでに現在のユーザーの本棚に登録されている場合は、重複登録させない。

```text
✓ この本はすでに本棚に登録されています

         [ 本棚で見る ]
```

この場合、読書状態・優先度・おすすめ度の新規登録フォームと「本棚に追加」ボタンは表示しない。

「本棚で見る」を押すと、対象の登録済み書籍詳細画面へ移動する。

## 9. 本棚への追加処理

### 9.1 登録前

- 必要な入力が揃っていれば「本棚に追加」を押せる。
- 「読んだ」でおすすめ度が未選択の場合、ボタンを無効化する。
- 登録前の確認ダイアログは表示しない。

### 9.2 登録中

ボタンの表示を以下に変更する。

```text
[ 登録中... ]
```

- ボタンを無効化する。
- ローディング状態を表示する。
- 処理中の二重送信を防ぐ。

### 9.3 登録成功

```text
検索結果の書籍詳細
       │
       │「本棚に追加」
       ▼
登録成功
       │
       ▼
本棚画面
       │
       ├─ 未読で登録 → 未読タブ
       ├─ 読んでるで登録 → 読んでるタブ
       └─ 読んだで登録 → 読んだタブ
```

本棚画面では、数秒間以下のメッセージを表示する。

```text
✓ 本棚に追加しました！
```

本棚一覧のスクロール位置は先頭にする。

### 9.4 登録失敗

- 現在の詳細画面に留まる。
- 選択済みの読書状態、優先度、おすすめ度を保持する。
- エラーメッセージを表示する。
- 登録ボタンを再度操作できる状態に戻す。

例：

```text
本棚に追加できませんでした。
もう一度お試しください。

[ 本棚に追加 ]
```

登録済みであることが判明した場合は、重複登録を促さず、登録済み書籍への導線を表示する。

## 10. 検索結果に戻る

画面上部の「← 検索結果に戻る」を押すと、書籍検索画面に戻る。

戻った際は以下を保持する。

- 検索キーワード
- 検索結果一覧

スクロール位置は先頭に戻す。

## 11. API・バックエンドとの関係

### 11.1 新規登録API

既存の想定エンドポイント：

```http
POST /users/me/books/from-search
```

現状のバックエンドでは、外部書籍IDと旧3段階の優先度を使って登録する仕様があるため、本画面の確定UXに合わせた改修が必要。

主な確認・改修事項：

1. 読書状態（未読・読んでる・読んだ）を新規登録時に指定できるようにする。
2. 優先度を「読みたい」「そのうち読みたい」の2段階に対応させる。
3. 「読んだ」で登録する際におすすめ度★1〜5を保存できるようにする。
4. 同じユーザーが同じ書籍を重複登録できないことを保証する。
5. 登録済みかどうかを判定し、登録済み書籍の詳細へ遷移できるようにする。

**注意：** 上記は画面仕様から導かれる実装要件。既存APIがすべて対応済みであることを意味しない。

## 12. この画面で扱わない機能

- 登録済み書籍の編集
- 本棚からの削除
- 気づきの登録・編集
- AI提案の表示
- 検索結果一覧の表示・検索処理

それぞれ別画面のMarkdownで定義する。

## 13. 確定事項

- 検索結果の書籍詳細画面は登録済み書籍詳細画面と分ける。
- 書籍情報は表紙・タイトル・著者・ジャンルを表示する。
- 読書状態の初期値は「未読」。
- 優先度の初期値は「読みたい」。
- 「読んだ」ではおすすめ度★1〜5が必須。
- 読書状態を切り替えても画面内の入力値を保持する。
- 登録済みの場合は新規登録フォームを表示しない。
- 登録前の確認画面は表示しない。
- 登録中は「登録中...」と表示し、ボタンを無効化する。
- 登録成功後は本棚の該当タブへ移動する。
- 登録失敗時は入力内容を保持する。
- 検索結果へ戻った場合、検索条件と結果を保持し、スクロール位置を先頭にする。

## 14. 実装時の確認事項

- 登録済み判定に利用するAPIとタイミング。
- 新規登録APIのリクエスト・レスポンスの改修内容。
- 優先度の旧3段階データから新2段階データへの移行方法。
- 登録成功時に本棚の該当タブを選択するための画面間状態の受け渡し。
- 共通ナビゲーションの正確な表示形式。
