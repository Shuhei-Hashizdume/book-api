# 気づき一覧画面 設計書

- ファイル名：`docs/design/screens/insights.md`
- 画面名：気づき一覧
- 設計状態：主要仕様確定
- 対象：ログイン済みユーザー

## 1. 画面の目的

ユーザーが登録した気づきを、書籍単位で整理して閲覧できるようにする。

気づきの本文を最初からすべて並べるのではなく、気づきが登録されている書籍を一覧表示し、ユーザーが書籍を選択すると、その書籍の気づき一覧へ移動する。

## 2. 画面の基本仕様

- 気づきが1件以上登録されている書籍だけを表示する。
- 気づきが0件の書籍は表示しない。
- 書籍ごとに、表紙画像・書籍タイトル・著者名・気づき件数を表示する。
- 書籍をクリック・タップすると、その書籍の気づき一覧画面へ移動する。
- 書籍の並び順は、各書籍に最後に気づきが追加された日時の降順とする。
- 同じ書籍に新しい気づきを追加した場合、その書籍が一覧の先頭に移動する。
- 他のユーザーが登録した気づきは表示しない。
- 本画面ではAI提案の内容を表示しない。

### PC版の配置

- 既存のBookAPP共通ヘッダー・ナビゲーションを利用する。
- メインコンテンツは中央寄せの読みやすい幅にする。
- 書籍を横長のカードとして縦に並べる。
- カード左側に表紙、右側にタイトル・著者・件数を配置する。
- カード全体をクリック可能にする。
- マウスホバー時には、クリック可能であることが分かる視覚効果を付ける。

## 7. 並び順の詳細

各書籍について、ログイン中のユーザーが最後に気づきを新規登録した日時を基準にする。

例：

```text
10/20  Python入門に気づきを追加
10/19  SQL入門に気づきを追加
10/18  習慣の力に気づきを追加

表示順：
1. Python入門
2. SQL入門
3. 習慣の力
```

その後、10/21に「習慣の力」に新しい気づきを追加した場合：

```text
表示順：
1. 習慣の力
2. Python入門
3. SQL入門
```

気づき本文の編集は、新規追加とは扱わない。

## 8. 例外・補助表示

### 表紙画像がない場合

- 代替の書籍表紙アイコン、またはプレースホルダーを表示する。
- 画像がなくてもタイトル・著者・気づき件数は表示する。

### データ取得中

- 書籍一覧の読み込み中であることが分かる表示を行う。
- 取得完了前に、誤って「まだ気づきがありません。」と表示しない。

### データ取得失敗時

- 「気づき一覧を読み込めませんでした。」と表示する。
- 再試行できるボタンを設ける。

### 書籍別気づき一覧から戻る場合

- 気づき一覧へ戻る。
- 最新のデータに基づいて書籍の表示順と件数を更新する。

## 9. バックエンドとの対応・実装時の確認事項

GitHubで確認した現行の気づきAPIには、書籍別の気づき取得エンドポイントがある。

```http
GET /users/me/books/{book_id}/insights
```

ただし、現在のAPIだけで、この画面に必要な「気づきがある書籍の一覧・件数・最新登録日時」を効率的に取得できるかは別途確認が必要。

実装時には以下を確認する。

- 書籍ごとの気づき件数の集計方法
- 気づきの新規登録日時を保持する方法
- 最後に気づきを追加した日時による書籍の並び替え
- ログインユーザーのデータだけを取得する認可条件
- 書籍の表紙・タイトル・著者情報の取得方法

**注意：** 現行の `routers/insights.py` では、気づき一覧の取得順が `Insight.id` の昇順になっている。今回の画面仕様を実現するには、取得処理や集計処理の見直しが必要になる可能性がある。

画面設計が確定したことと、バックエンドが対応済みであることは区別する。

## 10. 本画面に含めない機能

以下は別画面で扱う。

- 気づき本文の一覧表示
- 気づきの新規登録・編集・削除
- 気づきの詳細表示
- AI提案の生成・閲覧・再生成・削除

## 11. 確定事項と未決定事項

### 確定事項

- 気づきのある書籍だけを一覧表示する。
- 書籍ごとに表紙・タイトル・著者・気づき件数を表示する。
- 最後に気づきを追加した書籍を先頭に表示する。
- 書籍カードを選択すると書籍別気づき一覧へ移動する。
- 気づきが0件の場合は案内文と「本棚を見る」ボタンを表示する。
- PC版・スマホ版ともにカードを縦に並べる。

### 実装時に確認する事項

- 必要な集計APIの構成
- 新規登録日時を管理するDB設計
- 大量の書籍が存在する場合のページ分割方式
- 同一日時の書籍が複数ある場合の表示順

これらは、未確認の実装内容を確定済みとして扱わないために分けて記載する。
